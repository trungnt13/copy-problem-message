# Support

Copy Problem Context Agent is published as `tngo.copy-problem-context-agent`.

Use GitHub Issues for bug reports and feature requests:

https://github.com/trungnt13/copy-problem-message/issues

Include the VS Code version, extension version, operating system, command used,
and a small example of the diagnostic output when possible.

For copy-and-run issues, also include the configured value of
`copyProblemMessage.runSuffixMessage`.
